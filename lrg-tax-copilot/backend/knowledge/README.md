# Tax Knowledge Base

Drop `.md` files into this folder to add tax law knowledge to the copilot.

## How It Works
- All `.md` files in this directory are loaded into the AI's context on every request
- Files are loaded alphabetically — use number prefixes (01-, 02-) to control order
- Content is cached for 60 seconds, so edits take effect quickly without restarting
- No special format required — just write clear markdown

## Adding Content
1. Create a new `.md` file (e.g., `06-retirement-accounts.md`)
2. Write the tax law content in plain markdown
3. Save — the copilot will pick it up within 60 seconds

## Tips
- Be specific: include IRC sections, thresholds, dollar amounts, and effective dates
- Organize by topic: one file per subject area
- Include current year numbers: brackets, limits, phase-outs
- Note when rules changed (e.g., TCJA provisions, sunset dates)
