## Download & Install

### Recommended Method
Download the TaxAct Professional Installer: `TaxActProfessionalSetup.exe` (3.08 MB)

### Alternative Method (from Practice Manager)
1. Go to www.taxact.com/professional → Sign In
2. Enter Username and Password
3. Click **Orders & Downloads** tile
4. Click **Download** next to desired product, or use "Download our simplified installer" for multiple products
5. If install doesn't auto-run, locate and double-click the file (Ctrl+J in Firefox/Chrome to find downloads)

### Simplified Installer Steps
1. Open downloaded file → click **Next**
2. Accept License Agreement → click **Next**
3. Select the tax year to install
4. Choose products to install (click arrow to expand options)
5. TaxAct installs all selected products and notifies on completion

### Share Files on a Network (Enterprise Editions Only)

**Online Network Option** — Recommended for multiple preparers or multi-location access. Returns stored on TaxAct's secure servers.

**Local Network Option** — Returns saved to a chosen location on local drive/server. Folder should be in a shared network location for multi-computer access.

All users must sign in with TaxAct username/password on startup. Re-authentication required after 30 minutes of inactivity or 24 hours (whichever is sooner).

**Network Support Resources:**
- Windows Support: support.microsoft.com/en-us/products/windows
- TaxAct Network: taxact.com/support/22832/
- TaxAct Pro Support: taxactprofessional.com/support

### Install State Editions
1. Open a return → click **Return > State > Install State**
2. Select desired states or **Select All**
3. Click **Auto Install** (recommended) or **Manual Install** (for custom location/network)

### Adding/Removing States from a Return
- Open the return → **Return > State > Add/Remove State**
- Or from left navigation panel select **Add / Remove States**

### System Requirements
For best performance (especially large client lists or complex returns), exceed recommended requirements where possible. Refer to TaxAct's published minimum and recommended system requirements.

### Installation FAQs
- **Can't find downloaded file?** Use Ctrl+J in browser, check Downloads folder, or search for `TaxActProfessionalSetup.exe`
- **Error clicking install file?** Likely a partial download due to connection issues — re-download or try a different browser

## Set Up the Software

On first launch, the **Setup Wizard** walks through Master Information setup: Practice, Preparers, Client Status, Directories, and General categories.

Access anytime: **Preparer > Master Information**

Master Information is stored on TaxAct's Secure Servers, providing:
- Increased security
- More powerful practice management
- Return-level permissions and assignments
- Practice invitation status at a glance
- Activate/inactivate preparers

### Practice Information
Enter practice info as it should appear on tax returns, labels, letters, and correspondence. Info can be linked to each preparer. Click **Continue to Preparer Information** when done.

### Preparers Information

1. Click **Add New Preparer** (first preparer should be yourself/default preparer)
2. Check **Use My Practice Information** to link preparer to Practice address, or enter specific contact info
3. In Basic Information: selecting "IRS may discuss…" populates Third Party Designee with "PREPARER"
4. Enter "None" if no CAF number yet (requires Form 2848 to IRS)
5. Enter valid email for each preparer (required for network invitations)

**Default Preparer:** Change via dropdown in Preparers tab (Preparer > Master Information > Preparers)

**Practice ID:** Unique alphanumeric code assigned to practice. Same for all preparers. Found in upper right corner of TaxAct Account. Synced with EFIN and PTIN/SSN for e-filing.

### Electronic Filing Info — E-Filing Info

**EFIN Required:** Obtain from IRS — see "Become an Authorized e-file Provider" on IRS.gov

- Check "Use preparer information for E-file notifications" to receive e-file updates
- Both mobile phone and email required for notifications

**EFIN Verification:**
1. Sign in to TaxAct Account → Practice Administration tile
2. Click **EFIN Verification**
3. Enter EFIN and Tracking Number from IRS e-file Application Summary
4. Upload IRS e-file Application Summary (PDF preferred; JPG/BMP/PNG accepted)
5. Check authorization box → Click **Submit**
6. Status available within 2 business days; rejection notified via email

**Credit Card Info:** Only required for Pay Per Return e-file method. If bundle includes unlimited e-filing, no credit card needed.

### Permissions

**Practice Administrator** (first preparer, cannot be removed) can:
- Invite preparers to join practice
- Modify other preparers' permissions
- Activate/deactivate preparers
- Manage Data Management Tool (Practice Owner only)

**Practice and Preparer Permissions:**
- Edit Practice Information
- Edit Preparer Information
- Edit Client Status Options
- Change General Filing Settings
- Change Miscellaneous Settings
- Change Calculation Settings
- Edit Master Forms

**Client and Return Permissions:**
- Create New Returns
- Open Returns
- Remove Returns
- Import Returns
- Export Client Information (.csv or .txt)
- Print Returns
- E-file/Online Backup Returns

### Inviting Preparers
1. Complete Preparer Information → click **Finish**
2. Go to **Practice Administration** tile → **Preparer Invitation**
3. Complete details and click **Send Email Invitation**

Invited preparers get access to: Orders & Downloads, Professional Reports, Practice Administration (EFIN Verification only), Client Xchange (if purchased), Resources, My Info, My Preferences.

**No access to:** Preparer Invitation

### Client Status
Click **Add New Status** to create custom messages for Return Status and Payment Status columns in Client Manager.

### Directories
Displays where client documents are stored; allows changing locations.

### General
Options for filing/printing, calculation, and miscellaneous preferences.

## Integrated eSignatures (DocuSign)

Available for 1040 returns, state supported signature forms, and bank product applications. Files must be PDF or JPEG, 25MB per envelope limit.

### Request New eSignatures
1. From E-File Summary Steps → click **Start** next to "Request eSignatures", OR use eSignature tab
2. Select documents to eSign → click **Continue**
3. Add Sender/Recipient details, set reminders and expirations
4. Click **Continue to Payment**
5. Use available balance or credit card
6. Confirm charges → click **Review Envelope**
7. Customize Subject/Message if desired → click **Continue** to send

### Add New eSignatures
1. Click **Upload** → **Add Signature**
2. Click Add Signature dropdown → drag Signature rectangle to desired location
3. Click **Save and Close**

### eSignature Dashboard
View, track, manage, and edit eSignature documents. Options menu (dotted menu) includes:
- **Edit Request** — edit email, set reminders/expirations
- **Send Reminder** — email reminder to recipient
- **View History** — previous statuses
- **Download Forms** — download sent documents
- **Void Request** — cancel with optional reason

### Custom eSignature Requests
Click **Send Custom eSignature Request** → browse/select documents → add signatures → fill sender/recipient info → set expiration → confirm payment.

## E-Filing

### E-file Center
Access from within a client's return → click **E-file** button in navigation menu.

### E-file a Single Return
1. From E-file Center → click **Submit Electronic Filing Return**
2. Select **E-File** → click **Continue**
3. First-time: confirm Practice ID, EFIN, PTIN/SSN; verify EFIN
4. Protection Plus enrollment (if applicable)
5. Complete **E-Filing Summary** topics:
   - **IRS E-file Authorization** — Self-Select PIN or Practitioner PIN (Form 8879)
   - **IRS Refund Method** — bank products, direct deposit, or check (refund) / direct withdrawal, credit card, or paper check (liability)
   - **Driver's License Info** (optional)
   - **In Care of Info** (optional)
   - **E-File Alerts** — must fix for valid e-file
   - **Print Returns and E-File Documents** (optional)
   - **E-File Notifications** (optional)
   - **Request E-Signature**
6. Sign the return
7. Run **TaxAct Alerts** — fix errors/omissions
8. Pay associated fees (prepaid account or credit card)
9. Submit

### Batch E-Filing
1. Complete steps 1–8 for each return
2. On "Create and Submit" screen → choose **Submit Later** (places in holding directory)
3. When ready: **Preparer > Submit Client E-files** (or E-file Center → Submit Batch)
4. Check desired returns → click **Submit**
5. Confirmation window appears; email notification sent

## Protect, Backup, and Restore

### Password-Protect Client Returns
1. Open return → **File > Passcode > Add**
2. Enter passcode → click **OK**
3. Document all passcodes in a safe location

### Individual Usernames, Passwords & Permissions
All users sign in on startup. Re-authentication after 30 min inactivity or 24 hours. Use Permissions menu to limit return access per preparer.

### Back Up to Local Computer
1. **File > Backup > Client Return(s)** → select **Local** → **Next**
2. Check returns to back up → **Next**
3. Browse to backup location → click **Finish**
4. For Preparer Info: **File > Backup > Preparer's Information > Local**

### Back Up to TaxAct Servers (Enterprise)
1. **File > Backup > Client Return(s)** → choose **Online** → **Next**
2. Sign in to TaxAct Account
3. Select returns (and optionally check "Backup Preparer Master Information")
4. Click **Finish**

**Enterprise Online users:** Data automatically backed up — no manual backup needed.

### Restore from Local Backup
1. **File > Restore > Client Return(s)** → choose **Local** → **Next**
2. Browse to backup location → select files → **Next**
3. Browse to restore location → click **Finish**

### Restore from TaxAct Servers (Enterprise)
1. **File > Restore > Client Return(s)** → choose **Online** → **Next**
2. Sign in → select returns → optionally check "Restore Preparer Master Information"
3. Click **Authorize** → check email for authorization link
4. Complete authorization → return to TaxAct → **Next**
5. Browse to restore location → click **Finish**

## Printing

### Print Center
Access via:
- **Preparer** menu → any Print command
- From within a return → **Print** button in toolbar
- From within a return → **File > Print Client Returns**

### Set Printer Preferences
**File > Print Setup** → select printer → modify settings → **OK**

### Print Client Returns
**Preparer > Print Returns** → Client Returns tab → select returns → enter quantities → click **Select States** or **Select Reports** → **Print**

### Print Consent Forms
**Preparer > Print Consent Forms** → Consent Forms tab → select Client and Bank → enter copies → **Print**

### Print Client Organizers
**Preparer > Print Organizers** → select clients → choose **Print Applicable Organizers** or **Print Selected Organizers** → select items → **Print**

Organizer includes: Cover Sheet, Personal Information, Income, Deductions, Payments

### Print Labels
Print Center → **Labels** tab → choose Client Labels, Preparer Labels, or Other Labels

**Label Properties:** Set printer type, label size, font style/size → **Print**

### Print Reports
**Preparer** menu → Print Reports. Available reports:
- Adjusted Gross Income
- Average Client Fees
- Billing (Paid/Unpaid/All)
- Client Manager
- Contact List
- Mailing List
- Practice Summary
- Self-Employment
- Update Summary
- 2025 Federal Estimated Tax Payments
- Custom Reporting (export to CSV)

### Print Invoices/Billing Statements
From Client Manager → select client → right-click → **Print** → select desired report

## Integrated Payments (Drake Pay)

Access: TaxAct Account → Practice Manager → **Integrated Payments by Drake Pay**

### Apply
1. Click **Apply Now**
2. Complete application (follow on-screen instructions)
3. Processing: 1–3 business days
4. Check status in Practice Manager dashboard or Payments tab in software

### Collect Payments
1. In Client Manager → right-click client with balance due
2. Click **Collect Payment**
3. Fill out client card info including Amount to Pay
4. Click **Process Payment**

### Payments Tab
- View all payment history
- Click 3 dots next to payment → **Details** for payment info
- Click **Refund** to issue client refund

### Enable for Preparers
**Preparer > Master Information > Preparers** → edit preparer → Permissions tab → set "Allow" for Payment Collection and View Payment Manager → **Save and Close**
